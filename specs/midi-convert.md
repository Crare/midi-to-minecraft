# MIDI Convert Module

This module handles parsing MIDI files and converting them to Minecraft-compatible formats.

## Responsibilities

- Parse MIDI files
- Map MIDI events to Minecraft note blocks
- Generate schematic data and JSON outputs

## Main Files

- **src/**: Conversion logic (generate-block-sequence.ts, instrument-blocks.ts, etc.)
- **scripts/**: Build and utility scripts
- **output/**: Generated files

See the code in midi-convert/src/ for implementation details.
