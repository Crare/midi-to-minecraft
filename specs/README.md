# Project Specifications

This folder contains openspec specifications, architecture decisions, and explanations for the midi-to-minecraft project. Each file documents a specific section or component of the application, serving as guidance for AI agents and developers.

## Structure

- Each file in this folder describes a major part of the system, its responsibilities, and how it interacts with other parts.
- Use these specs as references for implementation, maintenance, and when making changes.

## Example Files

- architecture.md — High-level architecture and main components
- data-flow.md — How data moves through the system
- agents.md — Agent responsibilities and guidance
- webapp.md — Web application structure and UI
- midi-convert.md — MIDI conversion logic and pipeline

Add or update files as the project evolves.
